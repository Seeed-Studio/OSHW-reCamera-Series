# reCamera 2002 / 2002w products

English | [简体中文](README-CN.md)

The SG2002-based reCamera 2002 / 2002w family is sold in three main hardware
forms. They share the same modular platform but combine different sensor, base,
and motion hardware.

| Product | Camera hardware | Connectivity / motion | Hardware resources |
| --- | --- | --- | --- |
| Standard reCamera 2002 / 2002w | S101 OV5647, 5MP | B101; optional Wi-Fi/Bluetooth through the 2002w core | [C1 core](../core/c1-2002/), [S101](../sensors/s101-ov5647/), [B101](../base/b101-default/) |
| reCamera 2002 HQ PoE | S401 GC2053, 2MP, M12 lens | B301, 100Mbps Ethernet and 802.3af PoE Mode A | [Product page](hq-poe/) |
| reCamera Gimbal 2002w | S101 OV5647, 5MP | B401 CAN, 360° yaw and 180° pitch | [Product page](gimbal/) |

## Standard reCamera 2002 / 2002w

[![Standard reCamera 2002](../images/recamera-2002w.jpg)](https://www.seeedstudio.com/reCamera-2002-64GB-p-6252.html)

The standard fixed-camera form uses the three-board C1 + S101 + B101 stack.
The `2002w` core adds dual-band Wi-Fi and Bluetooth; storage configurations vary
by the currently selected storefront SKU.
