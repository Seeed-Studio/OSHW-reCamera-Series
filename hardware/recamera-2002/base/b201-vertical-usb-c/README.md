# B201 vertical USB-C base board

B201 rearranges the standard wired interfaces for a vertical USB-C mounting
orientation. This directory is a **reference/prototype design**, not the base
board shipped in standard reCamera 2002 Basic products.

The design provides USB-C, Ethernet, microSD, and UART functions. Editable
KiCad sources are in [PCB](PCB/) and enclosure files are in
[3D_Printed_Case](3D_Printed_Case/).

Validate USB power integrity, Ethernet magnetics, mechanical clearance, thermal
behavior, and EMC before deployment.
