# S101 OV5647 传感器板

[English](README.md) | 简体中文

S101 是标准 reCamera 2002/2002w 基础版产品随附的默认传感器板。

| 项目 | 参数 |
| --- | --- |
| 传感器 | OV5647，卷帘快门 |
| 分辨率 | 5MP（2592 × 1944） |
| 光学格式 | 1/4 英寸 |
| 像素尺寸 | 1.4µm |
| 光圈 | F2.8 |
| 焦距 | 3.46mm |
| 视场角 | 65° |
| 输出 | RAW10 |

该板还承载 reCamera 的麦克风、外接扬声器接口、四颗补光灯，以及状态/可编程 LED。
