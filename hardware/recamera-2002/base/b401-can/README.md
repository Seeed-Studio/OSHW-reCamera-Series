# B401 CAN base board

English | [简体中文](README-CN.md)

B401 is the CAN-enabled base board used by reCamera Gimbal 2002w. The restored
design files retain historical `B4` and `B101_B4_Gyro` filenames; these names
refer to earlier design naming, while current Seeed documentation calls the
commercial board B401.

| Directory | Contents |
| --- | --- |
| `PCB/B4_v0.1/` | Early KiCad design snapshot |
| `PCB/B4_v0.2/` | Later KiCad design and schematic PDF |
| `3D_Printed_Case/` | STEP/STL base enclosure files |
| `static/` | Board and schematic previews |

Verify the PCB revision against the physical product before manufacturing.
