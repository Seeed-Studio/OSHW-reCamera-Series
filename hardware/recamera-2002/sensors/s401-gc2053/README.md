# S401 GC2053 sensor board

S401 is a 2MP GC2053 sensor design associated with current reCamera 2002 HQ/PoE
configurations. It is an optional module, not the S101 board shipped in standard
Basic configurations.

| Item | Value |
| --- | --- |
| Sensor | GalaxyCore GC2053, rolling shutter |
| Resolution | 2MP (1920 × 1080) |
| Optical format | 1/2.9 inch |
| Aperture | F2.8 |
| Focal length | 2.9mm |
| Field of view | 93° diagonal / 84° horizontal / 54° vertical |

Editable KiCad files and the original design archive are in [PCB](PCB/).
Images are in [static](static/). Confirm that the repository revision matches
the commercial module before manufacture or service work.
