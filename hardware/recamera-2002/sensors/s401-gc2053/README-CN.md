# S401 GC2053 传感器板

[English](README.md) | 简体中文

S401 是与当前 reCamera 2002 HQ/PoE 配置相关的 2MP GC2053 传感器设计。它属于可选模块，并非标准基础版配置随附的 S101 板。

| 项目 | 参数 |
| --- | --- |
| 传感器 | GalaxyCore GC2053，卷帘快门 |
| 分辨率 | 2MP（1920 × 1080） |
| 光学格式 | 1/2.9 英寸 |
| 光圈 | F2.8 |
| 焦距 | 2.9mm |
| 视场角 | 对角 93° / 水平 84° / 垂直 54° |

可编辑 KiCad 文件和原始设计压缩包位于 [PCB](PCB/)，图片位于 [static](static/)。制造或维修前，请确认仓库版本与商业模块实物一致。
