# reCamera 2002 HQ PoE 硬件

[English](README.md) | 简体中文

[![reCamera 2002 HQ PoE](images/product.jpg)](https://www.seeedstudio.com/reCamera-2002-HQ-PoE-64GB-p-6557.html)

HQ PoE 是第一代 reCamera 2002 平台面向网络部署的固定式产品，由 SG2002
核心板、S401 GC2053 传感器板与 B301 PoE 底板组成。

| 项目 | 硬件 |
| --- | --- |
| SoC / 内存 | SG2002，256MB |
| 传感器 | GC2053，1/2.9 英寸 CMOS，1920×1080@30fps |
| 镜头 | 可更换 M12；官方默认视场角约 90° |
| 底板 | [B301 PoE](../../base/b301-poe/) |
| 传感器板 | [S401 GC2053](../../sensors/s401-gc2053/) |
| 网络/供电 | 100Mbps 以太网；802.3af PoE Mode A |
| 扩展 | 六针接口提供 UART、调试接口和三个 GPIO |

商城当前列出 64GB 配置，实际供货与所选存储容量应以商品页为准。
