# 第一代产品形态

[English](README.md) | 简体中文

基于 SG2002 的第一代目前以三种主要硬件形态销售。它们共用 reCamera 2002
平台，但采用不同的传感器、底板和运动机构。

| 产品 | 摄像头硬件 | 连接/运动 | 硬件资料 |
| --- | --- | --- | --- |
| 标准版 reCamera 2002 / 2002w | S101 OV5647，5MP | B101；2002w 核心板提供 Wi-Fi/蓝牙 | [C1 核心板](../core/c1-2002/)、[S101](../sensors/s101-ov5647/)、[B101](../base/b101-default/) |
| reCamera 2002 HQ PoE | S401 GC2053，2MP，M12 镜头 | B301，100Mbps 以太网与 802.3af PoE Mode A | [产品说明](hq-poe/) |
| reCamera Gimbal 2002w | S101 OV5647，5MP | B401 CAN，360° 水平旋转、180° 俯仰 | [产品说明](gimbal/) |
