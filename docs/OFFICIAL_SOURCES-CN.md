## 维护规则

- 保持本仓库为纯硬件仓库。软件资源只提供链接，不复制固件、模型、数据集、
  应用示例或 Node-RED 流程。
- 硬件先按 `recamera-2002` 和 `recamera-pro` 分类，只有确实存在模块化结构时才继续按板卡/模块细分。
- 规格变更必须记录官方来源 URL 和核对日期。
- 可编辑制造文件必须标明准确硬件版本，并区分出货产品、原型和参考设计。
- 官方产品页优先于本仓库中带日期的快照。
- 可在本地保留 Seeed 官方图片以保证硬件文档稳定，但必须在最近的 README 保留来源链接。
