The reCamera 2002 family is organized first by purchasable product form, then by
shared interchangeable core, sensor, and base boards. reCamera Pro is documented
as an integrated product because approved editable Pro design sources are not
currently stored in this repository. Both families remain part of the current
product matrix.

Repository files are revision snapshots, not an automatic statement that a
module is currently sold. Always distinguish standard shipped hardware,
optional modules, and reference/prototype designs.
