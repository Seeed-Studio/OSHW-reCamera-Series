# S101 OV5647 sensor board

S101 is the default sensor board shipped with standard reCamera 2002/2002w
Basic products.

| Item | Value |
| --- | --- |
| Sensor | OV5647, rolling shutter |
| Resolution | 5MP (2592 × 1944) |
| Optical format | 1/4 inch |
| Pixel size | 1.4µm |
| Aperture | F2.8 |
| Focal length | 3.46mm |
| Field of view | 65° |
| Output | RAW10 |

The board also carries the reCamera's microphone, external-speaker connection,
four fill LEDs, and status/programmable LEDs.
