# B101 默认底板

[English](README.md) | 简体中文

B101 是标准 reCamera 2002/2002w 基础版产品随附的底板。

## 接口

- USB 2.0 Type-C，用于供电、USB 网络和通信
- 通过单端口网络变压器实现的 10/100M 以太网
- microSD 卡槽
- 设计中引出的 UART、调试和用户控制接口

> [!WARNING]
> B101 以太网口不支持 PoE。连接以太网时，仍须通过 USB-C 给摄像头供电。
