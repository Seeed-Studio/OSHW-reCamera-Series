# reCamera Pro 硬件

[English](README.md) | 简体中文

[![reCamera Pro](images/product-hero.png)](https://www.seeedstudio.com/reCamera-Pro-2GB.html)

[前往 Seeed Studio 购买 reCamera Pro 2GB](https://www.seeedstudio.com/reCamera-Pro-2GB.html)

reCamera Pro 是基于 Rockchip RV1126B 的第二代 reCamera 平台。它不同于
reCamera 2002 的三板模块化结构，在本仓库中按集成了传感、音频、网络、供电和
扩展接口的整机记录。

## 官方硬件规格

以 Seeed Studio Wiki 为依据，核对日期：**2026-08-11**。

| 项目 | 规格 |
| --- | --- |
| 处理器 | Rockchip RV1126B |
| CPU | 1.2GHz 四核 Arm Cortex-A53 |
| NPU | 3 TOPS，支持 INT8/INT16 混合计算 |
| 内存 | 2GB / 4GB LPDDR4 |
| 存储 | 16GB eMMC；microSD 卡槽，最大 512GB |
| 摄像头 | 8MP SC850SL，最高 4K@30fps |
| IMU | ICM-42670-P 六轴加速度计和陀螺仪 |
| 音频输入 | 驻极体麦克风 ×2 |
| 音频输出 | 8Ω 扬声器，额定功率 1W |
| 网络 | 千兆以太网、双频 Wi-Fi、蓝牙 |
| 供电 | 12–24V DC（5525 圆孔接口）、PoE、7.4V 锂电池充放电管理 |
| USB | 全功能 USB Type-C（OTG） |
| 扩展 | 调试 UART、CAN ×2、GPIO ×2、22-pin MIPI DSI |
