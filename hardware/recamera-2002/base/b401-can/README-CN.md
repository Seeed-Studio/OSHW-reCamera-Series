# B401 CAN 底板

[English](README.md) | 简体中文

B401 是 reCamera Gimbal 2002w 使用的 CAN 底板。恢复的设计文件仍沿用历史上的
`B4` 和 `B101_B4_Gyro` 文件名；这些是早期设计命名，当前 Seeed 文档将商用板称为 B401。

| 目录 | 内容 |
| --- | --- |
| `PCB/B4_v0.1/` | 早期 KiCad 设计快照 |
| `PCB/B4_v0.2/` | 后续 KiCad 设计与原理图 PDF |
| `3D_Printed_Case/` | STEP/STL 底板外壳文件 |
| `static/` | 板卡与原理图预览 |

用于制造前，请将 PCB 版本与实际产品核对。
