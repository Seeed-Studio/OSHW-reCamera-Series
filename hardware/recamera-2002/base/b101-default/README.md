# B101 default base board

B101 is the base board shipped in standard reCamera 2002/2002w Basic products.

## Interfaces

- USB 2.0 Type-C for power, USB networking, and communication
- 10/100 Ethernet through a single-port transformer
- microSD card slot
- UART and debug/user controls exposed by the design

> [!WARNING]
> The B101 Ethernet port is not PoE. Continue to power the camera through
> USB-C when Ethernet is connected.
