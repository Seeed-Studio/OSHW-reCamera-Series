## Maintenance rules

- Keep this repository hardware-only. Link to software resources; do not copy
  firmware, models, datasets, application examples, or Node-RED flows here.
- Organize hardware by `recamera-2002` and `recamera-pro`, then by board/module
  only where that modular structure exists.
- Record the source URL and review date for specification changes.
- Mark editable manufacturing files with their exact hardware revision and
  distinguish shipped products from prototypes and reference designs.
- Official product pages take precedence over this dated repository snapshot.
- Official Seeed images may be stored locally for stable hardware documentation;
  preserve a source link in the nearest README.
